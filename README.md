# Music-player
<img width="602" height="361" alt="image" src="https://github.com/user-attachments/assets/53ecf7af-d1ef-493b-839c-a333999d801f" />

This music player is capable of playing music via bluetooth, even offline. I used esp32 module with a basic power circuit, connected esp32 to screen(TFT coloured), sd card, button, rotary encoder.
I got the idea to make it because I listen to music while i sleep and i have to use my laptop to do that, so instead i wanna make a player that i can use anywhere without getting some subscription.
